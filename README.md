# LUTPhoto

Terapkan LUT video (.cube) ke foto RAW tanpa editing manual. Sepenuhnya lokal.

## Prasyarat

- Python 3.10+

## Instalasi (butuh internet hanya satu kali ini)

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
